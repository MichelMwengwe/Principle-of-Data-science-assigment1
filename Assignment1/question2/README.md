# Question 2 — Student Performance Workflow

This project explores student performance patterns and academic differences.

## Purpose
- Load the student performance dataset
- Clean and standardize the data
- Handle missing values
- Create summary score features
- Generate charts and written findings

## Files
- Data: [data/StudentsPerformance.csv](data/StudentsPerformance.csv)
- Script: [src/q2_workflow.py](src/q2_workflow.py)
- Findings: [reports/findings.md](reports/findings.md)
- Missing values: [reports/missing_values.csv](reports/missing_values.csv)

## Run

python "question2/src/q2_workflow.py"
