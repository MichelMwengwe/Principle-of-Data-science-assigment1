# Question 1 — Frailty Workflow

This project analyzes frailty-related health data.

## Purpose
- Read the raw frailty dataset
- Convert units to standard measurements
- Create new features such as BMI and age groups
- Encode the frailty label and age categories
- Save the processed data and summarize key statistics

## Files
- Data: [data/frailty_raw.csv](data/frailty_raw.csv)
- Output: [data/frailty_processed.csv](data/frailty_processed.csv)
- Script: [src/q1_workflow.py](src/q1_workflow.py)

## Run
```bash
python "question1/src/q1_workflow.py"
```
